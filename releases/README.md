# Android APK Сборка

## Статус

✅ **Веб-приложение собирается успешно**
⚠️ **Android APK требует реального Android SDK**

## Что случилось?

Ваше приложение ДУЧАРХА правильно настроено для мобильной разработки с использованием Capacitor, но сборка APK файла не может быть завершена в облачной среде Replit из-за отсутствия Android SDK.

## Решение

### Для разработки (сейчас):
- ✅ Веб-приложение работает полностью: http://0.0.0.0:5000
- ✅ PWA функции настроены и работают
- ✅ Все мобильные плагины Capacitor подключены

### Для создания реального APK:

#### Вариант 1: GitHub Actions (Рекомендуется)
Настройте автоматическую сборку APK через GitHub Actions:
1. Загрузите код в GitHub
2. Создайте workflow файл `.github/workflows/android.yml`
3. Настройте секреты для Android signing
4. APK будет собираться автоматически при каждом push

#### Вариант 2: Локальная разработка
1. Установите Android Studio и Android SDK
2. Настройте ANDROID_HOME переменную
3. Запустите: `npx cap run android`

## Файлы

- `app-debug.apk` - placeholder файл (не функциональный)
- Для получения рабочего APK используйте GitHub Actions или локальную среду

## PWA как альтернатива

Ваше приложение можно установить как PWA на любое Android устройство:
1. Откройте приложение в Chrome на Android
2. Нажмите "Добавить на главный экран"
3. Приложение будет работать как нативное
